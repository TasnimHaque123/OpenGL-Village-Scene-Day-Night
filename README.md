# 🏡 Village Scene with Day & Night Cycle (OpenGL C++)

A 2D computer graphics project demonstrating a dynamic village scene featuring a seamless **Day & Night cycle**, moving vehicles, national flag, houses, and nature elements.

---

## Preview / Demo

![Village Scene](Village_Scene.mp4) 

---

## Features
* **Day & Night Cycle:** Dynamic change of background sky and sun/moon transition.
* **Animated Elements:** Moving vehicle/bus ("Ankhi"), fluttering flag, and environment.
* **Scenery Details:** Traditional village houses, trees, road, river/grassland, and Bangladeshi National Flag.
* **Graphics Library:** OpenGL (GLUT/FreeGLUT) in C++.

---

## Tools & Technologies Used
* **Language:** C++
* **Graphics Library:** OpenGL / GLUT
* **IDE:** Code::Blocks

---
